# Authplane .NET SDK — Complete LLM Reference

> Single `.slnx` for protecting MCP servers and OAuth 2.1 resource servers
> with tokens issued by an Authplane authorization server. Contains the
> framework-agnostic SDK (`src/Authplane/`) and a framework adapter for the
> official MCP .NET SDK's ASP.NET Core transport (`src/Authplane.Mcp/`).

## When To Use This Repository

Use this repo when you need to:
- implement or adjust .NET OAuth 2.1 discovery, metadata, JWKS, verification,
  or DPoP behavior
- evolve the stateful auth client (cache, circuit breaker, resilience)
- wire the verifier into ASP.NET Core / the MCP .NET SDK HTTP transport
  (`src/Authplane.Mcp/`)
- adjust adapter-level middleware / DI / challenge behavior and the demo host

## Layering Rules (Important)

1. All protocol verification, AS interaction, caching, and resilience logic
   lives in `src/Authplane/`.
2. The MCP adapter (`src/Authplane.Mcp/`) must stay thin: translate ASP.NET
   request contexts into core verifier calls and map core exceptions into
   framework-specific responses.
3. Do not duplicate verifier or token-parsing logic in the adapter.
4. Keep protocol operations stateless; keep cache / circuit / client state
   in the high-level client classes.
5. Each project has its own `<PackageId>` and is independently packable via
   `dotnet pack`. `Authplane.Mcp` declares `Authplane.Sdk` as a NuGet
   dependency through its ProjectReference.

## Key Design Patterns

### Error hierarchy
`AuthplaneException` is the root. Typed subclasses for each RFC error code
(`InvalidClientException`, `InvalidGrantException`, etc.), a `DPoPException`
base for all DPoP errors, `TokenRevokedException` for revocation. The
`AuthplaneErrors` static class provides `WwwAuthenticate(error, realm)` and
`HttpStatus(error)` helpers mapping exceptions to RFC 6750 challenges and
HTTP status codes.

### SSRF protection
`TransportSecurity.CreateHttpClient()` uses `SocketsHttpHandler.ConnectCallback`
for DNS-pinning: resolve hostname → validate all IPs via `IpValidation.IsAllowed`
→ connect to validated IP directly. Closes TOCTOU/DNS-rebind. Iterates IPs on
connect failure (python parity). Positive scheme allowlist (http/https only),
TLS 1.2+ minimum, userinfo rejection on all URLs.

### JWKS caching
`JwksCache` provides: lock-coordinated fetches (no stampede), background refresh
at 80% of effective TTL, effective TTL = min(configured, server Cache-Control/Expires
via `CacheHeaders.ParseExpiresAt`), stale fallback capped at 24h max-age,
force-refresh on kid miss, error callback for observability.

### DPoP (outbound)
Two levels: `ES256DpoPSigner` (low-level, ES256 only) and `DPoPProvider`
(high-level, ES256+RS256 via `DPoPKeyMaterial`, automatic nonce tracking via
`IDPoPNonceStore`). Both normalize htu via `DPoPHtu.Normalize()`.

### DPoP (inbound verification)
`AuthplaneResource.VerifyAsync` checks `cnf.jkt` in the access token, validates
DPoP proof (alg allowlist, typ, htm, htu, iat, exp, ath required when access
token present, nonce, replay store with shared instance lifetime).

### Conformance testing
Tests use `[Conformance("rfc...-case-id")]` attributes. A guard test
(`ConformanceCatalogAlignmentTests`) ensures every catalog case has a marker.

## API Examples

### 1) Client credentials flow (core)

```csharp
var auth = new AuthplaneAuthClient(
    issuerUrl: "https://auth.example.com",
    clientId: "client-id",
    clientSecret: "client-secret");

var token = await auth.ClientCredentialsAsync("tools/read");
```

### 2) RFC 8693 token exchange (core)

```csharp
var exchanged = await auth.TokenExchangeAsync(
    new TokenExchangeOptions("subject-token", resource: "https://api.example.com"));
```

### 3) DPoP with DPoPProvider (high-level)

```csharp
var keyMaterial = DPoPKeyMaterial.CreateES256();
var dpopProvider = new DPoPProvider(keyMaterial);
var headers = await dpopProvider.BuildHeadersAsync("POST", "https://as.example.com/oauth/token");
```

### 4) MCP adapter (`src/Authplane.Mcp/`)

```csharp
// See src/Authplane.Mcp/ and demo/ for the full ASP.NET Core wiring.
```
